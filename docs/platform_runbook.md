## 启动与停止

在 `C:\projects\ai-vocal-clone` 双击 `启动换声平台.bat`。默认浏览器将打开 `http://127.0.0.1:7866`，保持启动时的命令窗口运行。已启动时再次点击会打开现有页面，不会重复启动。

PowerShell 启动方式：

```powershell
Set-Location -LiteralPath 'C:\projects\ai-vocal-clone'
.\start_platform.ps1
```

如需更换端口，使用 `.\start_platform.ps1 -Port 7867`。使用 `-NoBrowser` 可以仅启动服务。

停止：双击 `停止换声平台.bat`，或者在启动窗口按 Ctrl+C。停止脚本会核对项目、PID 与进程命令，并在存在进行中任务时拒绝停止；不会停止其他 Python 或训练任务。

## 页面使用

1. 选择“带伴奏歌曲”或“纯人声 / 干声”，再上传音频。带伴奏模式会先分离人声与伴奏；男声/女声示例已经是干声，点击时自动选择纯人声模式。输入可以先试听，并显示实际波形。
2. 在“目标音色与参数”选“我的音色 · 第二版”“我的音色”或“清柔女声”。两版个人模型共用从《群青》留出的 12 秒原声，可用作试听参考。
3. 默认开启“自动适配目标音区”：从输入人声提取 RMVPE 音高，与现有目标训练特征的音区比较，在 0、-12、+12 半音中建议一个值，保留伴奏调性。它识别音高和音区，不判断人的性别。下方滑块为额外手动调整，最终值限制在 -12 到 +12；取消自动选项后，滑块直接决定转换音高。音色融合默认 75%。更多参数中可调辅音保护与音量包络。
   默认开启“静音与起音优化”：增加 0.4 秒头部和 0.5 秒尾部缓冲，转换后按原时间裁回；根据原声能量与原始 RMVPE 有声判断，柔和降低较长停顿中的残余声音。轻声有声段及其前后辅音、尾音留有保护范围。可取消勾选进行对照。
4. 点击“开始换声”，页面显示发送、分离、音区分析、换声、混音、回传等实际阶段。纯人声模式跳过分离和混音。
5. 完成后试听输入人声、转换人声和音量匹配对比，再下载 WAV。带伴奏模式还会提供原伴奏及“目标人声 + 原伴奏”整曲；输入人声播放器此时播放分离后的干声。对比文件的顺序为输入人声、1 秒静音、转换人声。
6. 任务保存后可在“最近生成”重新试听或下载，刷新和重新启动平台后仍然保留。服务中断的未完成任务会标记失败，可点击重试。

结果显示实际中位音高、音区、建议半音和本次使用半音。自动八度适配只是初始建议；假声、低八度唱法或较宽音域可以手动调整。混响、和声及密集乐器可能留在分离人声中，分离效果也需结合试听判断。

支持 WAV、MP3、FLAC、M4A、OGG、AAC、WMA、OPUS，单个文件上限 80MB、时长 0.2 秒至 10 分钟。WAV/FLAC/OGG 在导入时检查可读性；其他格式由服务器 FFmpeg 解码验证。浏览器不能预览的输入格式会在转换完成后提供标准 WAV 原声版本。最长时长也在服务器解码时检查，超限会显示失败提示。

## 本地页面与服务器的关系

本机运行 Python HTTP 后端与 HTML/CSS/JavaScript 页面，仅绑定 `127.0.0.1`。它通过系统已有 SSH/免密配置将待转换音频传到 `voice-gpu:/srv/ai-vocal-clone/.incoming/platform/<任务ID>/`，调用现有 Python/RVC 环境、选定音色的权重、音区参考和检索索引，再将结果回传。

因此当前版本需要能连到该服务器；本机无需安装 Torch/CUDA。它不是完全离线的本机 GPU 推理版本。没有创建云端网站或暴露公开端口，也没有新增登录系统。

GPU 任务在一个本地平台进程中串行执行，最多允许 3 个未完成任务。应用不会启动训练或修改现有模型。若另一个程序同时使用服务器 GPU，转换速度会受到负载影响。

| 文件或目录 | 作用 |
|---|---|
| `platform_app/server.py` | 本地 HTTP 服务、上传、任务队列、SSH 调用、音频服务 |
| `platform_app/static/` | 中文界面、交互、波形和播放器 |
| `scripts/platform_worker.py` | 服务器音频解码、调用现有推理、生成音量匹配对比 |

| `scripts/build_target_voice_profile.py` | 只读统计已有目标训练 F0，生成音区参考 |

| `reports/separation_assets.json` | 分离资源来源、固定 revision、字节数和 SHA-256 |

本地仅复用数据环境的 NumPy、SoundFile 和 Python 标准库，不需要 npm 安装或新增大型依赖。SSH 与 SCP 需要能在本机命令行调用。修改前端文件后刷新浏览器即可；修改 Python 后端后需重启平台。

## 常见情况

- **GPU 未连接**：先运行 `ssh voice-gpu` 确认服务器可达；网络或 VPN 恢复后，点击页面右上角刷新连接。
- **端口已被使用**：若已有平台，直接打开对应地址；其他程序占用时更换端口。
- **转换失败**：检查原音是否可播放，先用短 WAV 测试；展开结果区的任务日志查看原因。
- **超时**：单个远端任务有约 30 分钟的总超时限制，分离步骤最长 650 秒，RVC 步骤最长 720 秒。较长音频可拆成几段，速度也受共享 GPU 负载影响。SSH 断开后服务器侧也有运行时间上限。
- **目标音色**可选六段录音训练的个人第二版、三段录音训练的个人第一版或公开歌手。任务记录会保存当次选定的版本。

## 分离与音区适配实现（2026-11-07）

带伴奏输入先解码为 44.1kHz 立体声，交给 BS-RoFormer 分离。伴奏取原混音减去估计人声的残差；两条声部使用同一重采样滤波器转为 40kHz。仅人声送入 RMVPE、RVC 和静音优化，转换后严格裁回输入时间线，再与未变调的立体声伴奏合成。回混人声音量参考分离前的人声音量，并对整曲使用共同增益预留峰值余量。

分离器使用服务器已有的 PyMSS 2.0.14，权重为 `model_bs_roformer_ep_368_sdr_12.9628`，来自 [PyMSS 模型仓库](https://huggingface.co/baicai1145/pymss/tree/f02318ef92c43472777ed7aeeded3d2b29a68b58/vocal/vocal_extraction)。通过 `scripts/download_separation_model.py` 下载并校验，来源和哈希记录在 `reports/separation_assets.json`。不改动 RVC 上游源码和已训练权重。

目标音区参考由已有 1169 个训练 F0 文件统计得到：p10 为 188.6Hz、中位数 263.3Hz、p90 为 369.8Hz；这些特征含插值，只作音区参考。输入分析使用未插值的 RMVPE F0，并排除无声和极低能量帧。

25 项自动测试通过，其中新增覆盖音区建议、静音帧过滤、自动/手动音高、立体声回混、削波控制、时间线校验、新音频接口和实时处理阶段。真实推理结果见 `reports/separation_validation.json`。浏览器已验证音频类型切换、自动音区开关、恢复默认、重启历史恢复和整曲播放，结果截图在 `reports/separation-platform-ui.png`。

真实 GPU 验证已完成：

- 已知干声加合成伴奏的 24.213 秒样例：分离约 10.53 秒、远端处理约 51.61 秒、含传输约 69.1 秒。相对已知干声的 SI-SDR 从 2.11dB 提升到 35.65dB，已知安静区的残留能量降低约 38.73dB。这只说明该合成测试的分离表现，不能推为任意歌曲的效果。
- 既有明确授权的 101.162675 秒实际录音：分离 12.72 秒、远端处理 36.67 秒、含传输 186 秒。分离人声、转换人声、原伴奏和整曲全部回传，均为 40kHz，时间线一致、数值有限、无检测到的数字削波。自动建议原调。
